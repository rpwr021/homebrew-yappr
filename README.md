# homebrew-yappr

Homebrew tap for [Yappr](https://github.com/rpwr021/yappr), local push-to-talk
dictation and voice chat for macOS.

## Install

```bash
brew install rpwr021/yappr/yappr
```

or:

```bash
brew tap rpwr021/yappr
brew install yappr
```

## Update

```bash
brew upgrade --cask yappr
```

The cask in `Casks/yappr.rb` is updated automatically by the Yappr release
workflow on each release.
